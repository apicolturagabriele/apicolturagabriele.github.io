# Apicoltura Di Giuseppe Gabriele

Sito di Di. Di. P di Di Giuseppe Gabriele, Via Case Cicchetti, 64024 Notaresco (TE).

Sito statico pubblicato con GitHub Pages, in stile classico e caldo.

Sei pagine (`index`, `chi-siamo`, `prodotti`, `apicoltura`, `adotta-un-arnia`, `contatti`) più `privacy.html`. Stile in `stile.css`, script in `sito.js`, font in `fonts/` (Cormorant Garamond per i titoli, Source Sans 3 per i testi).

## Foto
Foto e logo recuperati dal vecchio sito Jimdo, ottimizzati in `img/` (webp). Se una foto manca, al suo posto compare il motivo a favo.

## Moduli
Adozione e contatti non usano email: al clic su Invia si apre WhatsApp con il messaggio già compilato verso il numero di Gabriele (`WA_NUM` in fondo a `index.html`).
